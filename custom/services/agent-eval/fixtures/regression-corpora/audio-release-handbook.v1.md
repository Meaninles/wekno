# Northbank 音频栏目交付手册（新分布回归语料）

## 版本与状态

“拼接稿”“审听稿”和“可发布版本”是不同状态。把文字说明改成“可发布”不会改变音频本身的状态，也不会更新发布系统。较新的、已签署授权可以替代同一受访者的旧授权；这不表示旧文件已经被删除。

## 权利核验

原始人声轨在权利核验完成前不得公开发布。引用这条禁令进行知识问答，不等于禁止检索手册。权利状态没有得到明确确认时，必须标记为待确认，不能依据已经完成录音推断可以发布。

## 文字稿与无障碍

机器转写只能视为草稿。文字稿需要人工核对姓名与专有名词；无障碍审核是另一项独立状态。人工核对完成不能推断无障碍审核也已完成，反之亦然。

## 交接信息

一次交付交接至少记录栏目代号、音频版本、权利状态、文字稿状态、制作负责人和计划发布窗口。未知字段应明确保留为待确认，不得用建议值或历史值填充。

## 外部操作边界

在聊天中撰写公告、修改交接说明或分析发布条件，不会自动上传音频、发送公告、更新任务板或执行发布。外部操作只有在用户明确要求、相应权限可用且系统留下真实执行结果时，才可表述为已经完成。
