# Juniper 编辑发布手册

## 稿件记录

稿件记录应区分稿件编号、工作标题、声明语言、投稿作者、协调编辑、内容复核人、复核生命周期和仍待补的材料。编辑计划的目标读者属于计划级信息；除非记录明确绑定到具体稿件，否则不能把它填成该稿件的目标读者。当前聊天的发言人也不能在没有声明时自动成为投稿作者、权利人或发布负责人。

## 角色与复核

协调编辑负责整理来稿材料和安排编辑流转；内容复核人负责评估稿件证据与内容风险。指定或更换内容复核人只确定角色归属，不表示复核已经开始、没有开始、完成或未完成。只有明确的用户陈述、复核结论或编辑系统记录才能确定复核生命周期。

## 接收与发布

进入正式接收判断需要已签署的原创声明和完成的权利检查表。缺少其中一项时，只能把相应材料记为待补，不能据此断言稿件已被拒绝或不符合接收条件。校样获得认可也不等于稿件已经发布；实际发布还需要发布负责人明确授权，并有内容管理系统返回成功事件。没有发布事件只能使发布状态保持未知，不能单独证明尚未发布。

## 风险与假设

稿件中出现可识别个人的家庭住址属于需要立即升级给法律与安全团队的高风险内容；普通标点不一致属于常规编辑问题。对另一篇稿件、示例文本或假设风险的分析，不得自动写入当前稿件记录，除非用户明确把该事实绑定到当前稿件。

## 对话与外部操作

聊天中修改发布备注、清单或摘要，只改变当前对话里的文字，不会创建稿件、修改内容管理系统、写文件、发送邮件或发布内容。只有相应外部工具返回成功结果，才能声称这些操作已经完成。解释发布限制或检索本手册不构成发布授权，也不证明发布已经发生或没有发生。
