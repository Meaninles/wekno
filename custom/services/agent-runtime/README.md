# Agent Runtime

AgentScope 2.0.7.post1 是唯一问答运行循环；Go 提供授权业务工具和持久 Run 状态。
各类型独立保留。知识问答固定 15 次，其他类型固定 50 次。

- `app/run.py`：SDK 组装与执行。
- `app/budget.py`、`delivery.py`：模型预算及最终候选答案。
- `app/artifact_delivery.py`：本轮输出基线、纯代码校验、持久发布与最终提交。
- `app/control.py`、`state.py`、`events.py`：Go 状态协议、检查点和事件。
- `app/reasoning.py`：模型声明的内联思考协议到 SDK 思考/正文块的转换。
- `app/workspace.py`、`kubernetes_workspace.py`：隔离文件与专业技能运行环境。
- `uv.lock`：固定依赖。普通问答的工作区延迟创建。

Docker 工作区使用默认 `bridge` 网络以允许直接访问互联网，但不加入包含
WeKnora 数据库和基础设施的内部业务网络；只读根文件系统、权限降级和资源限制仍然保留。

预算由 Go 的运行账本统一持有。`runs/budget` 在每次决策前返回累计 Token、
请求次数、剩余时间和最终回答预留；模型租约在事务中执行同一约束。
非知识问答默认 300 万累计 Token，知识问答保持 100 万，调用次数默认 100。
配置分别为 `AGENT_RUNTIME_MAX_TOTAL_TOKENS`、
`AGENT_RUNTIME_KNOWLEDGE_QA_MAX_TOTAL_TOKENS`、`AGENT_RUNTIME_MAX_MODEL_REQUESTS`。
输入使用混合语言估算单位，按当前运行相同模型角色的实际 usage 校准并留出余量；
这是估算，不是假定 UTF-8 字节数等于 Token，也不宣称精确 tokenizer 计数。
保留一次主模型最终回答的额度，辅助模型不能使用；准入拒绝后转为同一次 SDK 决策的
无工具收尾，不补发已经生成的答案。SDK HTTP 自动重试关闭；建连失败可由传输层重试。
尚未交给 SDK 任何内容的 429/500/502/503/504 响应最多再尝试一次，每次重新申请并结算
预算租约。预算拒绝、其他 4xx、网络中断及已开始输出的响应不由这项机制重试。

文件发布成功即为持久成果。可生成文件的运行失败后，有已保存文件时返回
`status=incomplete`、`failure_code` 与文件下载链接，消息正文明确说明未全部完成；
流式完成事件的 `extra` 同样包含状态和文件。此事件表示响应结束，不表示任务成功。
没有成果仍走统一错误，用户主动停止不会变为成功。历史记录与其他渠道使用同一正文。
工具返回图片仅作简短事实与可读性观察，使用独立调用目的；新写入和编辑后的文本进入
SDK 文件缓存，连续编辑仍核对远端内容，避免额外读取并防止覆盖外部变更。
不完整工具参数以工具错误交还同一 SDK 循环，事件序列化不能将其升级为整轮异常；
不执行或猜补非法参数，也不增加独立重试循环。
可生成文件的非知识问答运行还会将较大的已授权业务工具结果无损保存到工作区
`/workspace/source-data/`，供代码直接读取结构化数据进行转换和导出。模型收到路径及明确标记的局部预览，按需读取完整数据；引用契约和来源元数据保持完整。
输入数据及最终发布文件继续使用各自既有权限边界。

开发编排为 `custom/docker-compose.agent-runtime.yml`，复用当前 API 和基础设施。
运行 `uv run pytest` 检查 SDK 协议；真实开发验证脚本见 `custom/tests/agent_runtime`。
成品保存到 `/workspace/outputs`，输入、脚本、预览和临时文件放在其他目录。
执行前持久化路径与哈希基线，只自动发布本轮新增或内容变化且通过适用文件可用性校验的成品。
校验与发布不调用模型，不评价内容正确性。Worker 不持有业务数据库或对象存储账户凭据。

模型 `parameters.extra_config.reasoning_format` 默认为 `native`，使用服务返回的
原生思考字段。对已确认把 `<think>…</think>`（或聊天模板预填开启标记后仅返回
关闭标记）放在 `content` 中的 OpenAI Chat 服务，设置为 `think-tags`。
这是提供方输出协议，不按模型名称、智能体类型、问题或对话 ID 推断。
转换在 SDK 累积消息、生成事件与检查点之前完成，不使用答案去重、二次生成或前端遮盖。
该协议的首段在结束标记出现前有歧义，需要暂存；出现标记后正文正常流式输出。
没有标记的普通正文在响应结束时释放。原生协议的流式时延不受影响。
代码块、引用及行内代码中的字面标记保留；显式开启但未关闭的思考块按不完整响应处理。

完整实现与验证边界见 [说明](../../../docs/custom/统一AgentHarness实现方案.md)。

运行通过 `runs/finalize` 原子进入 `finalizing`，持久化候选答案及执行结果；模型和业务工具准入随即关闭。代码交付阶段冻结写入进程、比较原基线、校验和上传，再将附件列表与消息一起提交。发布确认丢失或 Worker 重启后，只恢复交付；每次交付有独立的十分钟 I/O 窗口，待交付文件不因模型超时而清理。用户主动取消仍终止任务。完成校验的字节版本直接上传，Go 核验落盘哈希并提供私有下载。

模型工具目录已移除发布工具；最终回答的路径、链接和文字不参与产物发现。原有回答路径解析、漏写发布声明报错及要求模型改写交付答案的分支已删除。详见[预算与产物交付](../../../docs/custom/统一运行预算与文件部分交付.md)。
