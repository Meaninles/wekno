# WeKnora 使用指南包（生产版）

> 代码、路由与配置核对日期：2026-09-13。生产 Web 入口为
> `https://knora.moutai.com.cn/`，API 基地址为
> `https://knora.moutai.com.cn/api/v1`，移动端入口为
> `https://knora.moutai.com.cn/mobile/`。

本包只面向使用本平台的终端用户，以及基于 WeKnora 已提供的 API、MCP、SDK、CLI、IM
回调和嵌入页开发外围应用的团队。平台内 Agent 的配置与使用说明也包含在内；不包含修改
WeKnora 源码、内部运行时或部署系统的开发资料。清单按照当前工作区源码、路由、配置和
已有公共文档整理，不是整个代码仓库的压缩备份。

## 包含内容

- 用户登录、知识库、文档、会话、Wiki、分享和常用管理操作；
- 平台 Agent 类型、配置、工具、知识范围、技能、文件产物和使用方法；
- API 参考、客户端 SDK、CLI、MCP、IM、嵌入页、OIDC、RBAC、共享空间和向量库接入；
- 当前实现下可直接帮助使用方理解的分块、知识图谱和内置模型/MCP 说明。

## 地址和凭据约定

- 面向生产使用的示例统一使用 `https://knora.moutai.com.cn`；API 示例使用其
  `/api/v1` 路径，移动端使用 `/mobile/` 路径。
- `http://localhost:5177`、`http://localhost:8080` 只在明确标注为本地开发/验收的章节中
  出现，不能复制到生产配置；本地移动端仍使用 `http://localhost:5177/mobile/`。
- API Key、Token、密码、签名密钥、对象存储凭据、模型地址、节点地址和租户数据只用占位符
  或受保护配置说明表示。请将示例中的 `<...>` 值替换为当前授权范围内的临时或受控配置，
  不要把真实值写入文档、命令历史或 Git。

## 明确不包含

本包不包含生产停机/回滚剧本、内部架构诊断和历史验收证据、测试夹具与测试数据、`.env`
及密钥文件、Compose/Helm/部署源配置、内部服务 README、运行时 `SKILL.md` 指令、模板、
二进制文件、截图/PDF 验收产物或其他只供仓库维护者使用的材料。

如需了解代码事实与文档维护边界，请在仓库内阅读[当前实现架构与文档索引](../当前实现架构与文档索引.md)
和[文档同步核对记录](../文档同步核对记录-20260913.md)；二者不属于本使用指南包的主体清单。
