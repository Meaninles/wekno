# 当前生产实现与部署基线

> 代码与配置核对日期：2026-09-13。本文以当前工作区中的源码、配置和部署模板为准，不以提交记录推断实现。
>
> 生产访问地址统一使用 [https://knora.moutai.com.cn](https://knora.moutai.com.cn)。API 基地址为 `https://knora.moutai.com.cn/api/v1`，移动端为 `https://knora.moutai.com.cn/mobile/`。本文件不记录生产节点、内部服务、对象存储、模型网关、命名空间、仓库、路径、租户标识或任何凭据。

## 1. 核对范围与真源

本次基线来自以下当前文件的实际内容：

- 路由与 API 能力：`internal/router/router.go`、`internal/custom/bootstrap/bootstrap.go` 及对应 `internal/custom/modules/`。
- 智能体类型、模式、预算和能力开关：`internal/types/custom_agent.go`、`config/agent_type_presets.yaml`、`config/builtin_agents.yaml`。
- 运行时角色与副本数：`helm/values-production-ha.yaml`、`custom/tests/runtime_profile_e2e/docker-compose.yml`。
- 前端入口：`frontend/src/` 下的 Web、移动端、嵌入式和分享路由实现。
- API/MCP 公共约定：`docs/api/`、`custom/services/weknora-mcp-policy/` 以及当前 Swagger 生成文件。

历史文档只作为背景资料；当历史描述与上述源码或配置冲突时，以当前源码或配置为准。

## 2. 对外访问约定

| 能力 | 生产地址 | 说明 |
|---|---|---|
| Web 平台 | `https://knora.moutai.com.cn` | 终端用户登录和使用平台 |
| API | `https://knora.moutai.com.cn/api/v1` | 租户、知识库、会话、智能体、Wiki、MCP 等 API |
| 移动端 | `https://knora.moutai.com.cn/mobile/` | 与 Web 同源的移动端入口 |
| 嵌入式应用 | `https://knora.moutai.com.cn/embed/{channel_id}` | `{channel_id}` 为平台生成的嵌入渠道 ID |
| 分享页面 | `https://knora.moutai.com.cn/share/chat/{token}` | `{token}` 只使用实际生成的分享令牌；文档不得写入真实令牌 |
| 安全嵌入交换 | `https://knora.moutai.com.cn/api/v1/embed/{channel_id}/exchange` | 由受信业务后端完成安全交换 |
| IM 回调 | `https://knora.moutai.com.cn/api/v1/im/callback/{channel_id}` | 具体渠道由平台配置生成 |

本地开发/验收地址仅用于本地章节：Web 为 `http://localhost:5177`，API 为 `http://localhost:8080`，移动端为 `http://localhost:5177/mobile/`。本地移动端不使用 `5178` 端口；这些地址不代表生产入口。

## 3. 生产角色与副本基线

生产高可用模板当前表达的业务角色如下。基础数据库、缓存、图数据库和对象存储为独立基础设施，本文只描述业务侧依赖，不披露其地址或凭据。

| 角色 | 副本/执行方式 | 主要职责 |
|---|---:|---|
| API | 3 | HTTP API、会话、知识库、智能体及管理能力 |
| 解析 | 3 | 文档解析和解析任务调度 |
| 衍生任务 | 2 | 文档衍生内容、切片等异步处理 |
| Wiki | 2 | Wiki 索引及相关异步任务 |
| 维护 | 2 | 队列维护、清理和后台维护任务 |
| 迁移 | 1 次性 | 数据库迁移；完成后退出 |
| DocReader | 3 | 文档读取基础设施与运行时读取任务 |
| Agent Runtime | 2 | 受控智能体运行时任务 |
| 前端 | 2 | Web 静态资源和前端服务 |
| 移动端 | 2 | 移动端静态资源和服务 |

副本数以 `helm/values-production-ha.yaml` 的生产模板为准；本地角色验收编排以 `custom/tests/runtime_profile_e2e/docker-compose.yml` 为准。二者的资源、入口和基础设施地址不可互相替代。

## 4. 文档处理与容量边界

- 任务状态、队列和租约由持久化存储及队列组件共同维护；解析、衍生、Wiki、维护和 DocReader 通过角色隔离运行。
- 生产解析并发、队列并发和 DocReader 资源限制由 Helm 生产配置控制；文档不得把某一台节点或某个 Pod 名称当成固定接口。
- 生产入口允许的公共知识源上限为 2048 MiB；普通文件和 DocReader 解析文件上限为 50 MiB；反向代理请求体上限为 2304 MiB；内部产物上传代理上限为 128 MiB。
- 文件类型、解析方式、切片、向量化、重排、图谱和衍生任务的实际支持范围以当前配置与代码校验为准，不能仅凭历史文档扩展承诺。
- 阶段任务完成以阶段状态和租约语义为准；不要用“某个容器已经退出”替代业务完成判断。

## 5. 智能体运行时基线

当前统一使用 `agent_mode: agent`。能力由 `agent_type`、能力开关、知识库/数据源选择、工具白名单和技能配置共同决定，不再把“快速问答模式/智能推理模式”作为新建智能体的两种运行模式。

当前类型为：

`knowledge-qa`、`wiki-qa`、`hybrid-rag-wiki`、`data-analysis`、`table-analysis`、`document-processing-agent`、`general-agent`、`knowledge-base-manager`、`custom`。

当前内置定义包括：

- `builtin-knowledge-qa`
- `builtin-data-analyst`
- `builtin-table-analyst`
- `builtin-general-agent`
- `builtin-document-processing`
- `builtin-wiki-fixer`（内部 Wiki 修复用途）

迭代预算由类型和是否启用产物能力共同决定：知识问答默认 15；启用产物时为 100；其他普通情况为 50。内置数据分析、表格分析、通用智能体和文档处理智能体按当前配置使用产物能力和 100 次迭代。实际模型、工具和技能仍受租户配置、权限和运行时白名单约束。

Agent Runtime 不应直接获得数据库、对象存储或平台管理凭据。运行时通过受控回调/API 使用平台能力；文件上传后会经过大小、类型、摘要/哈希和安全校验，运行目录及产物访问受任务和租户边界保护。

## 6. 存储、网络与安全边界

- 生产关系型数据使用 PostgreSQL/ParadeDB 能力，队列使用 Redis，图谱能力使用 Neo4j，文件使用受保护的对象存储；具体连接信息由受保护的生产配置注入。
- 生产对象存储不依赖共享 RWX 文件系统；运行时临时目录、工作区和产物目录按角色/任务隔离。
- API 密钥、模型密钥、OIDC 密钥、Webhook 密钥、对象存储凭据、数据库密码和加密主密钥不得写入文档、示例、日志、提交或压缩包。
- 示例中的密钥统一使用 `<TENANT_API_KEY>`、`<MODEL_API_KEY>`、`<EXTERNAL_SERVICE_KEY>`、`<SHARE_TOKEN>` 等不可用占位符；用户应通过平台配置或部署密钥管理注入真实值。
- 生产启用 release 模式时不把 Swagger UI 作为公开生产入口；Swagger 交互调试只适用于允许调试的非 release 本地环境。

## 7. 发布、迁移与回滚要求

1. 发布前从当前源码构建不可变镜像，并固定镜像摘要；不要用“最新”标签推断正在运行的版本。
2. 通过受保护的生产配置注入域名、数据库、缓存、对象存储、模型和第三方集成信息；公开文档只写逻辑能力与生产域名。
3. 先执行一次性数据库迁移，确认成功后再滚动更新各业务角色；避免并行执行重复迁移。
4. 发布后校验入口、数据库、缓存、对象存储、DocReader、队列消费者、Agent Runtime、MCP 和前端资源。
5. 回滚必须同时评估镜像、数据库迁移、对象存储产物、队列消息和配置变更；禁止只回滚某个 Pod 就宣称完整回滚。

本地后端验收遵循根目录 `AGENTS.md`：使用角色化 Compose，不使用单体 `app-dev` 作为启动方式；本地 API 入口固定为 `http://localhost:8080`。本文不把本地启动命令当成生产部署命令。

## 8. 完整验收清单

- 使用生产域名验证 Web、API、移动端、分享、嵌入式和 IM 回调路径；示例令牌均为占位符。
- 验证知识库创建、文件/URL/文本导入、解析状态、检索、会话、反馈和导出能力。
- 验证 Wiki、混合检索、图谱开关、数据源连接和权限边界。
- 逐一验证九种智能体类型、工具白名单、技能、产物、文件上传、迭代上限和多轮会话。
- 验证解析、衍生、Wiki、维护、DocReader、迁移和 Agent Runtime 的副本/租约/故障恢复语义。
- 验证 MCP 工具白名单、输出包装、递归脱敏、下载限制、OAuth/审批和跨租户隔离。
- 验证生产日志、文档、构建产物和使用指南中没有密钥、真实令牌、私有地址、节点 IP、内部路径或租户标识。
