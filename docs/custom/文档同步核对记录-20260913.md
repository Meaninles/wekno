## 2. 当前实现摘要

- 生产 Web：`https://knora.moutai.com.cn/`；API：
  `https://knora.moutai.com.cn/api/v1`；移动端：
  `https://knora.moutai.com.cn/mobile/`。
- 本地开发/验收：前端 `http://localhost:5177`，移动端
  `http://localhost:5177/mobile/`，API `http://localhost:8080`；本地后端使用角色化
  runtime profile，不使用单体 `app-dev`。
- Agent 类型为 `knowledge-qa`、`wiki-qa`、`hybrid-rag-wiki`、`data-analysis`、
  `table-analysis`、`document-processing-agent`、`general-agent`、
  `knowledge-base-manager`、`custom`。
- 当前内置定义为 `builtin-knowledge-qa`、`builtin-data-analyst`、
  `builtin-table-analyst`、`builtin-general-agent`、`builtin-document-processing` 和
  内部 Wiki 修订智能体；旧 ID 仅作兼容迁移说明。
- 预算规则由后端统一计算：知识问答 15；启用产物能力为 100；其他普通类型为 50。
- Agent Runtime 使用统一 `agent` 运行模式；Python 侧由 AgentScope Harness 执行，Go
  侧负责身份、权限、工具回调、持久状态和产物登记。生产不公开模型名称、节点或网关地址。
- 生产角色数量以当前覆盖为准：API 3、parse 3、derivative 2、Wiki 2、maintenance 2、
  migration 1 次性、DocReader 3、Agent Runtime 2、frontend 2、mobile-web 2。

## 3. 文档处理和安全口径

- 对外示例的主机地址统一改为生产域名；localhost 只保留在带有“本地开发/验收”标题的
  启动、测试和端口转发说明中。
- 将真实或疑似真实的 API Key、Token、密码、签名密钥、私有 IP、内部 DNS、节点名、
  namespace、绝对路径、镜像 digest、业务租户/用户/知识库、客户/订单和测试证据路径
  移除或替换为 `<...>` 占位符。
- API 示例只使用合成 ID 和占位凭据；返回敏感字段时说明“已掩码/不返回明文”，不复制
  生产响应。
- 生产停机、回滚、迁移、容量调整和受保护配置文件仍保留在仓库内部文档，但不纳入面向
  用户/开发者的使用指南 ZIP。
