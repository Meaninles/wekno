## 修改

- 删除聊天资料选择器的类型特判：所有智能体按知识库范围、权限和工具能力展示整库及文件。
- 删除编辑页旧简单对话限制。它错误匹配通用智能体，会隐藏知识库配置并在保存时将其设为 `none`。
- 所有内置配置、新建表单及 API 未指定字段时，图片和音频上传均默认开启。显式关闭仍然有效。
- 新建表单从当前租户模型列表选择默认 VLM、ASR；保留已指定的模型。
- 配置迁移版本 4 一次性开启现有未删除智能体的两个开关，缺少模型时选择本租户模型。迁移有事务及并发锁；再次运行不覆盖用户之后的选择。
- 未增加模型调用、回答纠正或对话专用规则。
