# 开发指南

> 当前开发环境核对日期：2026-08-12。当前本地后端固定使用
> `custom/tests/runtime_profile_e2e/docker-compose.yml` 的分角色编排，不使用单体
> `app-dev`、`make dev-app` 或 `scripts/dev.sh app`。

## 基础设施

```bash
cp .env.example .env
make dev-start DEV_ARGS="--minio --neo4j"
```

基础设施必须包含 PostgreSQL、Redis、MinIO、Neo4j 和基础 DocReader。Qdrant、Milvus
等其他依赖按 `.env` 的实际配置启用对应 profile。

## 分角色后端

本地编排包含 API 3 个、解析 2 个、衍生 2 个、Wiki 2 个、maintenance 2 个、一次性
migration 1 个、runtime DocReader 2 个及两个入口。API 入口为
`http://localhost:8080`：

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml build runtime-api-1
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml up -d --force-recreate
```

后端代码修改后先执行 `down`，再按上面的顺序 build 和 up：

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml down
```

状态和日志：

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml ps
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml logs -f runtime-entry runtime-api-1
```

## 前端

```bash
cd frontend
npm ci
npm run dev -- --host 0.0.0.0 --port 5177
```

桌面端访问 `http://localhost:5177`，移动端访问
`http://localhost:5177/mobile/`；本项目本地移动端不使用 `5178`。前端 `/api` 和
`/files` 默认代理到 `http://localhost:8080`。
