# 快速开发模式

> 本页仅适用于本地开发。生产多副本、OBS/RWO 存储和数据迁移见
> [当前版本生产更新部署执行手册](../../custom/当前版本生产更新部署执行手册.md)。

本项目本地后端固定使用 `custom/tests/runtime_profile_e2e/docker-compose.yml` 的
分角色编排。该编排不是单体 `app-dev`，也不使用 `make dev-app`、
`scripts/dev.sh app` 或 Air 启动后端。

## 启动顺序

### 1. 启动基础设施

在项目根目录执行：

```bash
make dev-start DEV_ARGS="--minio --neo4j"
```

这一步负责 `docker-compose.dev.yml` 中的 PostgreSQL、Redis、MinIO、Neo4j 和
基础 DocReader。确认这些容器已运行后，再启动运行时角色。

### 2. 启动分角色后端

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml up -d --force-recreate
```

本地运行时角色为：

| 角色 | 实例数 |
|---|---:|
| API | 3 |
| 解析 | 2 |
| 衍生任务 | 2 |
| Wiki | 2 |
| 维护 | 2 |
| 迁移 | 1（一次性） |
| DocReader 运行时 | 2 |
| API 入口 | 1 |
| DocReader 入口 | 1 |

基础 DocReader 仍由 `docker-compose.dev.yml` 提供 1 个基础设施实例，因此
DocReader 总数为 3。API 入口对外暴露 `http://localhost:8080`。

### 3. 启动前端

```bash
cd frontend
npm install
npm run dev -- --host 0.0.0.0 --port 5177
```

桌面端访问 `http://localhost:5177/`，移动端访问同一端口下的
`http://localhost:5177/mobile/`；本项目本地移动端不使用 5178 端口。

## 后端代码修改后的重建

后端代码修改后，先停止当前 runtime profile，再构建共享镜像并重新创建全部角色：

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml down
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml build runtime-api-1
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml up -d --force-recreate
```

`runtime-api-1` 使用同一份 Go 后端镜像，构建它即可构建共享镜像；不能只重启某个
旧的单体服务。重新拉起前仍需确保基础设施已由 `make dev-start` 启动。

## 查看状态和日志

```bash
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml ps
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml logs -f runtime-api-1
docker compose -p weknora-runtime-profile-e2e \
  -f custom/tests/runtime_profile_e2e/docker-compose.yml logs -f runtime-parse-1
```

## 目录约束

二开逻辑放在 `custom/` 或 `internal/custom/`，原生代码只保留必要注册点；修改前先
阅读 [二开目录结构规范](../../custom/二开目录结构规范.md)。
