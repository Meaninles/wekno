# 开启知识图谱功能

开发环境在 `.env` 配置 `NEO4J_ENABLE=true`、URI、用户名和密码，并使用
`docker compose --profile neo4j up -d` 启动。生产使用 Kubernetes Secret 注入
凭据，并保证全部 app 副本可访问 Neo4j Service。

然后在知识库中启用图谱索引和实体/关系抽取，选择有效模型，上传具有已知关系的
测试文档。成功必须同时核对：

1. 主解析和启用的摘要、问题/图谱、Wiki 全部完成。
2. Neo4j 中该知识库/文档的节点和关系真实存在。
3. 图谱查询或关系问题能召回预期关系和来源。
4. 重建不会被旧 generation 覆盖，删除能清理图谱和 Wiki 来源。

Wiki 页面链接图与 Neo4j 实体图不同。大图使用分类、搜索、分页和中心节点一跳图；
点击关联节点会以它为新中心。

详细步骤以[仓库开启指南](../../开启知识图谱功能.md)和
[知识图谱说明](../../KnowledgeGraph.md)为准。
