# 知识图谱

WeKnora 同时支持 Neo4j 实体关系图谱和 Wiki 页面链接图：

- 实体关系图谱由 LLM 从文档抽取，服务 GraphRAG 和智能体关系查询。
- Wiki 页面链接图来自页面入链/出链，服务分类浏览和关联阅读。

大规模 Wiki 图采用“分类列表/搜索 → 选择中心节点 → 一跳邻接图”的渐进模式。
点击任一关联节点会把它设为新中心继续加载；不会一次性展示整库全图。邻居过多
时分页，概览默认 500、最大 2000 个节点。

完整配置、API、完成性和故障排查请阅读仓库文档：

- [知识图谱与大规模关联浏览](../../KnowledgeGraph.md)
- [开启知识图谱功能](开启知识图谱功能.md)
- [常见问题](../运维排障/常见问题.md)

实体图成功必须同时满足文档完整工作流成功、Neo4j 节点/关系存在和真实关系查询
可召回；不能只看 Neo4j 进程或文档主解析状态。
